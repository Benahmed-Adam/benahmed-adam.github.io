À propos du projet

Chatterbox est une application de messagerie instantanée pour Android. L'application est développée avec Flutter tandis que le backend est fait en PHP.

Fonctionnalités principales

Chat en temps réel

Envoi et réception instantanés de messages de groupe.

Gestion des utilisateurs & groupes

Inscription, connexion, création de groupes et gestion des groupes.

Android

Uniquement sur Android.

Backend robuste

API REST PHP + MySQL.

Architecture technique

L'application utilise Flutter pour l'interface utilisateur. PHP est utilisé pour le backend (gestion des utilisateurs, messages, groupes, ...) et MySQL pour la base de données.

Apprentissages

Ce projet m'a permis de maîtriser Flutter et Dart. J'ai également appris à gérer l'état d'une application complexe et à implémenter un système de messagerie instantanée.
