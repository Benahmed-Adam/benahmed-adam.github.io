À propos du projet

simple_http_server est un serveur HTTP développé from scratch en C++ dans le but de comprendre en profondeur le fonctionnement des protocoles réseau et du web. Ce projet minimaliste se concentre sur l'essentiel : servir efficacement des pages statiques.

Fonctionnalités principales

100 % Windows natif

Utilise uniquement WinSock - aucun besoin de bibliothèques tierces, compilation directe avec un simple compilateur C++.

Static files only

Parfait pour servir HTML/CSS/JS/images localement ou sur LAN.

Support IPv4 & IPv6 natif

Prêt pour les réseaux actuels sans configuration supplémentaire.

Ultra-léger & rapide

Serveur HTTP minimaliste en C++ sans aucune dépendance externe — parfait pour tester rapidement des pages statiques.

Apprentissages

Ce projet m'a permis d'explorer les sockets réseau en C++, la gestion des threads et la compréhension détaillée du protocole HTTP.
